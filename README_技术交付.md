# LOONG JUMP 系统修正版技术交付

请先阅读：

1. `docs/业务流程与修复清单.md`：业务口径、8 项缺陷修复与新增管理能力。
2. `docs/服务器部署与恢复.md`：Docker／Node 部署、员工账号、数据库迁移、完整备份及恢复步骤。
3. `docs/验收记录.md`：测试结果和实际验证范围。

目录说明：

- `app/`、`lib/`：业务界面与服务。
- `db/`、`drizzle/`：数据模型和全部数据库迁移。
- `server/`：独立公司登录、数据库和文件适配、备份恢复及启动程序。
- `dist-node/`：已经构建的自有服务器运行产物（技术交付 ZIP 内）。
- `Dockerfile`、`compose.yaml`：容器部署。
- `tests/`：自动化回归与真实 HTTP 服务测试。
- `pnpm-lock.yaml`：锁定依赖版本。

源码包不包含正式数据库、密码、发货照片视频或员工会话。迁移现有业务数据时请由管理员从修正版在线系统导出完整 TAR 备份。

运行 `pnpm test` 可重做验证。自有服务器入口是 `node server/index.mjs`，不要以普通 `pnpm start` 替代。
