# 国内分销批量导入与回款归集验收

日期：2026-11-26。范围：本地开发与合成数据验收，尚未推送或发布，未操作正式业务数据。

## 业务行为

1. 在「国内线下分销 → 订单与履约」增加「一键导入订单」。每次为一张客户订单批量导入 SKU 明细，支持 Excel / XLS / CSV，最多 300 行。先选客户、填写订单和结算信息，再预览并确认导入；保存后为草稿，继续原有报价、合同及审批流程。
2. 表格字段为 SKU、数量、人民币单价，商品名称可选。支持下载模板。未知 SKU、重复 SKU、非正整数数量、零/负价格、超过两位的人民币小数及公式单元格会阻止导入，不会悄悄忽略错误行。
3. 新建和修改订单时选择现金结算、账期、定金或寄售。账期、定金、寄售须填写约定回款/结算日；现金可填写约定日期。定金另填合同放货金额。合同审批仍核实最终条款，供应链不能确认收款。
4. 负责供应链或管理员可提交客户付款金额、付款日期、参考号、说明和图片/PDF凭证。凭证只进入待核，不增加已回款，也不解除发货限制。
5. 财务独立核实公司实际到账，可关联一份待核凭证录入实际金额、到账日期、银行参考号与公司银行凭证，也可填写原因退回。客户填报金额与实际到账金额分别保留；同一凭证不能重复核销。
6. 财务及管理员在财务工作台集中查看国内待核付款及应收款分类，能打开原凭证和来源订单。约定回款日、已核回款、剩余款项、逾期状态可追踪。工厂不读取客户付款和财务金额。
7. 原核销冲销后，客户凭证保留原处理记录并提示查看最新流水。完整备份包含客户付款原文件、提交及复核记录；小品岗位手册同步更新。
