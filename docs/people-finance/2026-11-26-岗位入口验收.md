# 按岗位分配个人工作与审批入口

状态：本地完成，未发布。基于主分支 `136ca06abb91c23f0f5de94a5762d331711c1d82`。

## 入口与职责

| 岗位 | 我的工作 | 团队处理 |
| --- | --- | --- |
| 所有岗位 | 每日打卡、请假申请 | 仍按已有组织及显式授权 |
| 运营 | 另有广告申请、广告趋势分析 | 本人提交申请并查看进度，趋势受站点和渠道权限限制 |
| 运营主管 | 另有广告趋势分析 | 按授权审批团队申请 |
| 管理员、财务 | 个人打卡、请假 | 广告审批，不显示广告申请或趋势快捷入口；管理员身份不会绕过审批授权 |

侧栏与手机菜单统一使用正常导航样式，个人页默认不混入团队记录。个人列表、汇总、操作记录和导出使用相同范围。小品岗位手册及待办跳转同步更新；审批待办直达对应申请。

## 飞书边界

员工在飞书工作台的考勤中打卡、申请请假；本系统展示同步的本人记录，管理页按授权查看。个人页面不新增重复的本地打卡、请假流程。旧本地记录保留，旧未签退班次和未完成审批仍可收尾。

本次核对的私密凭据文件中 App ID 与 App Secret 均为空，真实飞书连接及员工绑定尚待完成。界面不得将无同步记录解释为缺勤或零请假。现有考勤 API 同步已生效及撤销的请假事实，不表示覆盖飞书所有待审批或驳回申请。
