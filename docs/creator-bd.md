# 五站达人与直播 BD

入口：日常工作 → 达人与直播 BD（`?page=creators`）。覆盖印尼、马来西亚、泰国、越南、菲律宾，按国家、平台、店铺管理。流程参照用户提供的《五国达人BD协同工作与管理办法》；未将单一市场的样品数量、奖励或考核示例设成五站强制规则。

## 首次配置

1. 管理员在用户管理创建「达人BD」岗位账号。
2. 在「店铺与分工」为实际店铺指定一名主责运营、一名 BD，可补充备份运营。一名运营可以在这个模块负责多个站点，不扩张其销售或库存权限。
3. 运营为视频达人、直播主或两者兼有的账号建档，填写平台唯一 ID、联系信息、匹配依据、证据与下一步负责人和时间。
4. 分工修改后，当前待办交接给新负责人；原始来源运营和历史操作人保留。

上线不预置真实人员分工、店铺、达人或合作条件，也不自动创建账号。

## 岗位协作

| 岗位 | 工作范围 |
| --- | --- |
| 管理员 | 五站总览、店铺分工、独立审批合作和延期、终止合作、查看与导出台账 |
| 运营 | 已分配店铺的建档、触达、回复、意向交接、真实寄样及签收登记、内容验收、观察与交付复盘 |
| 达人BD | 已分配店铺的承接／退回／排队、商务条件提案、关系维护、复合作及分层 |
| 运营主管 | 查看五站协作与导出，不代替执行或审批 |
| 财务 | 查看五站台账，核验累计贡献与费用凭据，留痕修订及导出 |

BD 同时保留原系统全员可见的脱敏生产动态。BD 无销售导入、改库存、批发审批、付款、公司财务总账及账号管理权限。未分配的运营或 BD 不能读取或修改其他店铺记录。

## 闭环

候选 → 已触达 → 有回复 → 待 BD → 洽谈中 → 履约中 → 复盘维护。

- 交接须有明确回复、意向 SKU、形式与排期、费用诉求及证据。BD 承接、退回或排队均需写明原因、下一步及期限。
- BD 逐轮提交 SKU／样品数、视频／直播数量、预算币种和上限、佣金、验收条件、素材授权、库存核对及交付时区；管理员批准后执行。新轮次不能覆盖旧轮次。
- 样品登记引用真实出库单、物流单和证据。当前按本轮全部约定样品发出后登记一次；实际库存出库仍在既有仓库流程完成。本模块不会再扣一次库存。
- 运营登记签收、视频链接或直播回放，逐项核对链接、SKU、准确性和约定要求。播放量低不直接判为不合格；不合格内容可复验。
- 已约定的内容全部验收、需要寄样的轮次已签收，才能完成交付并安排后续复盘。并行轮次中完成或终止其中一轮，不会把其他轮次错误标为已完成。
- 原始截止时间保留；延期须另行独立批准，原始和延期后的准时率分别展示。
- 7 天／30 天效果观察须等窗口成熟，缺失指标留空，不视为零。观察修订保留全部版本。

## 财务与管理口径

财务逐轮填写**累计净收入和累计成本**。净收入已扣退款与折扣；分别核对商品、平台、佣金、履约售后、样品、寄样运费、奖励及可归属广告费。已在净收入扣除的项目须明确标识，额外扣除额为 0，防止重复扣费。

每项费用、净收入和汇率都要有依据。系统保留原币贡献，并按财务确认的汇率折合人民币；这不是自动获取平台结算数据或自动付佣金。修订只替换当前汇总值，历史版本不可覆盖，凭据不能重复归属多个合作轮次。已有财务关账规则仍生效。轮次或交付发生变化后，旧核算标为待复核。

总览分别显示 7 天回复率、14 天首合作率、60 天复合作率以及准时交付率；保留分子、分母与未成熟数量，小样本提示，不以未成熟样本考核。首合作从 BD 首次承接起算，以合作获批为节点；复合作从首轮交付完成起算，以第二轮交付完成为节点。关系分层为试合作、成长、核心、暂停；核心须有至少两轮完整合作、完整且有效的正贡献核算、近 60 天核验订单与明确复合作意愿。

Excel 导出包含达人档案、合作轮次、合作 SKU 明细、内容记录、效果观察、财务版本、跟进历史、统计口径八张表，遵守当前账号权限与筛选范围。不是奖金、工资或付款指令。

## 实现与验收

- `0034_creator_bd.sql` 增加独立协作台账；历史、财务版本和观察记录不可变，完整备份与恢复覆盖新表。
- 每次变更检查当前账号、店铺分工、记录版本及协作时钟，状态更新和历史在同一事务提交；重试、过期页面和并发换人不会静默覆盖。
- API 使用现有公司登录会话，校验来源并隔离其他岗位接口。
- 证据采用共享文件／账单／平台内容链接；本期无平台自动抓取、自动消息发送或新的附件托管。
- 本地预览只使用合成演示数据。原始管理办法及真实业务资料不进入公开仓库。

自动化覆盖范围：跨站分工、越权、唯一 ID、完整交接与多 SKU 履约、独立审批、延期、窗口成熟、财务修订及关账、重复凭据、并发、备份恢复、各岗位真实会话、脱敏生产动态与并行合作状态。
