# 五国达人与直播 BD

入口：日常工作 → 销售看板下方的「达人与直播 BD」（`?page=creators`）。

本次按《达人管理修改意见》调整现有模块。主流程是**运营移交已完成初次合作且有出单依据的达人 → BD 接收并分配 → 深度合作 → 履约与效果复盘 → 经验复用**。不要求 BD 重填已发生的触达、回复及初次合作；旧记录原样保留。仅本地开发，暂不发布。

## 五个工作区

1. **协作总览**：达人资产、本月提交、待接收、跟进中、复合作进行中、S/A 优质达人；五国分布、最新运营移交、实际待办。全盘按平台唯一账号去重，同一达人有跨国关系时可在各国出现，国家数量不应直接相加。
2. **达人档案**：同平台账号一个主档案；按国家和店铺保留合作关系、联系人、责任人及多轮合作。支持国家、平台、BD 评级、阶段、负责人、提交月份和 ID 搜索。四区展示基础资料（含能力画像与核验贡献）、运营初始表现、BD 维护、合作历史。
3. **运营提交**：手工填写、Excel/CSV 预览校验、去重、修订历史，以及 BD 接收队列。
4. **合作与履约**：在已有达人上创建新合作，独立审批预算和条件，登记寄样、签收、视频或直播验收、完成交付，记录本轮效果及复盘。财务核算在本区展开，不另增顶层页面。
5. **经验复用**：达人开发、视频、直播、产品匹配、达人维护五类方法，以及关联已完成合作的案例。独立审核后共享；不要求每轮强行凑一篇经验。

「协作设置」位于页头，配置店铺分工和 BD 组长；不是额外工作区。

## 账号与分工

| 岗位 | 范围 |
| --- | --- |
| 管理员 | 五国查看、店铺配置、显式设置/撤销 BD 组长、分配 BD、独立审批合作与延期、经验审核、导出 |
| BD 组长 | 由管理员显式指定的有效「达人BD」账号；五国协作查看、店铺及负责人配置、接收、评级、跟进、履约和经验审核 |
| 普通 BD | 仅本人负责的达人；店铺默认负责人与达人单独分配并存，单独分配优先。不能把自己设为组长或越权转派 |
| 运营 | 已配置店铺内录入，查看/修订自己的提交；运营初始表现和 BD 评级分别保存；可协作履约及填报效果 |
| 运营主管 | 五国查看与导出、独立审核经验；不代替商业审批或财务核算 |
| 财务 | 五国查看、累计费用和贡献核验、修订、凭据及导出 |

组长不是新建所有 BD 的默认权限。本次不创建真实账号、不预设真实组长。来源运营从登录账号和有效店铺分工取得，不接受表格填写姓名冒充归属；管理员代录归店铺主责运营。更换负责人不改原始提交人、历史合作和操作人。普通 BD 接收某位达人的单独分配，不获得同店其他达人的权限。

本模块不开放销售导入、库存调整、公司付款、账号管理等额外权限。

## 运营移交

主导入表严格保留 12 列：创建日期、月份、国家、达人ID、TK主页链接、达人联系方式、达人类型、合作方式、达人数据、达人分类、运营评估等级、视频内容与创作能力标签。另附填写说明页，不带可误导入的示例数据行。

- 月份自动从创建日期推导；手填不一致会报错。每批同一店铺，1–50 行，先校验再提交；任何错误整批不写入。
- 达人类型为视频、直播或两者；合作方式为纯佣或付费（兼容历史混合方式）；分类为出单且勤快、出单不勤快；保留七类创作标签。
- 「达人数据」可填写真实合作表现；也可用 `粉丝数:...;订单量:...;GMV:...;币种:IDR;平均播放量:...`。金额须保留原币种，旧模板“元”不能自动当人民币。文本说明不自动计入财务核验贡献，缺失数字保持空值。
- 提交须确认已合作出单，并提供联系方式、类型及出单表现。提交即创建待 BD 接收档案；未知历史信息不虚构，不自动补触达/回复时间。
- 规范化平台 ID，全公司主档案按「平台＋账号」归集；不同国家/店铺保持独立业务关系。同一资料换文件重传或同批重复跳过；不同后续提交追加至原档案。
- 原提交运营可持续修订自己的资料，追加不可变历史；不改达人 ID、创建日期、需求类型。修订不会覆盖 BD 评级、意向、维护备注或已审批合作。
- BD 接收须记录意见、负责人、下一步及时间，直接进入「待深度合作」。退回补充或暂不接收均留原因与下次跟进，不删除记录。

## BD 维护与合作

运营评估与 BD **S / A / B / C** 评级独立。BD 记录合作意向、维护备注、唯一负责人、最近跟进、下次行动和时间；评级不代表财务已确认盈利。

阶段：待 BD 接收 → 待深度合作 → 沟通中 → 待寄样 → 履约中 → 已完成；支持暂停与恢复。阶段从实际有效轮次计算：有待寄样轮次时显示待寄样，存在活跃履约时不因另一轮完成而提前完成。已完成达人可以开启新的合作轮次。

- 合作选已有达人，填写 SKU/样品数量、纯佣/付费、需要寄样时的收件资料、约定视频/直播数、验收要求、预算和币种、佣金、授权、截止时间与时区。视频合作不强制填直播；直播合作不强制填视频。
- 管理员独立批准后，由运营或负责 BD 登记真实寄样、签收、内容与验收。样品引用真实仓库出库单和物流证据，此处不再扣库存。
- 已约定内容全部验收、需要寄样的轮次已签收，才能完成交付。原始截止日保留，延期独立审批。
- 完成后可记录统计日期、实际订单/GMV/合作成本、评价、后续计划和依据。缺失金额不为零，修改生成新版本，不累加同一轮不同修订，也不把 BD/运营自报写成财务已核验贡献。
- 每条内容保留 7 天/30 天观察，窗口未成熟不填成熟结论；重叠窗口不相加。

历史「候选、首次触达、回复、交接」接口与记录保留兼容，前台主流程不再要求这些步骤。原有能力画像及其历史可以从档案基础资料展开维护。

## 经验和财务边界

方法经验可独立提交，有场景、步骤、实际效果、适用边界和佐证即可，不强制关联已完成轮次。BD 组长、管理员、运营主管可独立审核，作者不能自审。仅审核通过且确认可共享的内容跨国展示；未审核草稿、私人联系资料和财务原始台账不随案例公开。

关联合作的经验仍保留来源内容、原版本、财务核验状态和复用结果；来源被修订后必须复核，才能新引用。复用时重新审批商务条件，不自动复制预算或授权。

财务逐轮记录累计净收入和费用：商品、平台、佣金、履约售后、样品、运费、奖励、可归属广告。已在净收入扣除的费用明确标识，避免再次扣费。每次修订只替换当前汇总，保留原币、凭据、汇率和不可变历史；关账约束及重复结算凭据校验继续生效。履约变更后旧核算显示待复核。

系统不自动抓取平台、不自动发消息、不自动付款或发奖金。佐证为获准访问的链接，未新增附件托管。

## 存储、升级与验证

- 既有 `0034`、`0035`、`0038` 记录原样保留。新增 `0039_creator_handover.sql` 创建主档案关联、BD 独立字段、显式组长配置、合作效果修订、方法经验与审核历史。
- 升级时将历史同平台账号归至一个主档案，为过去未关联的运营提交补建档案。缺少真实接收/触达/回复记录时保持未知，不伪造历史成功状态。
- 所有变更在维护锁、有效账号、权限、版本和协作时钟校验后原子提交。效果修订另检查最新修订号，防止旧表单覆盖。历史不可删除或改写。
- 全部新表纳入完整备份恢复；不会修改销量、库存或资金。
- 自动化覆盖：重复文件/重复账号、跨国主档案、普通 BD 隔离与组长撤销、转派后权限、运营修订与独立评级、直接接收至 BD 履约、视频/直播条件、效果版本与空值、经验审核与自审阻止、并发维护锁、旧数据升级、备份恢复。
- 本地合成预览：`scripts/creator-workflow-preview.mjs` 和 `scripts/creator-workflow-preview-server.mjs`，固定 `127.0.0.1:57321`，不读取正式后台及真实表格。
