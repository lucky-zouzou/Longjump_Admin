# 销售看板与导入说明

## 每日录入

运营在“每日销售导入”选择日期并填写平台报表/订单批次号，下载模板填写后上传 Excel / CSV。当前账号只能操作负责的站点和渠道。管理员、运营主管、供应链、工厂沿用原销售查看权限；运营只能查看自己的范围。

| 列 | 填写方式 |
| --- | --- |
| SKU | 必填。前导零请保留文本格式；同款跨站点必须使用相同编码才能合并销量。 |
| 商品名称 | 选填。 |
| 数量 | 非负整数；普通销量大于0。有投放未出单的SKU可填0，但投放成本必须大于0、销售额为0或留空。 |
| 成交单价 | 选填，实际成交单价。 |
| 销售额 | 选填，当前行实际成交金额，优先于“成交单价×数量”，可填扣除折扣后的金额。 |
| 投放成本 | 该行SKU在该统计日期的广告成本。空白表示未知，明确无投放填0。同一笔成本只填一次；店铺总费用在“渠道广告总费用”登记一次，没有SKU明细时留空，不按行重复填写或虚构分摊。 |
| 币种 | 默认当前站点本币：IDR、MYR、THB、VND、PHP；也支持USD、CNY。同一行销售额、单价和成本必须使用相同币种，导入保留原币金额，不能只改币种标签；看板另行计算人民币参考汇总。 |

金额列使用数字，不带货币符号；小数点用英文句点，最多两位小数，可用英文逗号作千位分隔。例如 `1234.56` 或 `1,234.56`。印尼本地格式 `1.234,56` 请先转换为 `1234.56`。表头支持中文及常见英文别名；未识别时可按模板修改表头。文件第一张表不正确时可切换工作表。

预览后确认才写入。相同文件或同一站点、渠道、日期、报表编号会阻止重复扣库。完整销售和投放数据建议放在同一份SKU日报：如果过去只导入了销量，需要补录成交额/成本，使用销售导入管理的批次修订，保存后会按原流程校正库存；单纯重复店铺广告费使用专用核对入口。零销量成本行可记录独立的额外广告支出，但不能代替补全旧批次中的未知成本。

## 看板口径

- 日期可选近7天、近30天、本月或自定义，单次最多366天。不是仅统计最近100批或1000条销售。
- 全站销量榜按SKU合并当前权限、日期、站点及渠道范围内的所有币种，展示排名、商品、总数量、占比和覆盖站点数。可搜索、分页、导出全部数据。
- 上方“人民币经营汇总”将当前权限和筛选范围内的已填报原币金额统一折算；下方“原币明细”按钮仍只筛选原币，金额、销量、均价使用一致范围。
- ROAS = 销售额合计 ÷ 广告投放成本合计；不是逐行ROAS的平均值，也不是利润率。
- 同SKU同币种在当前范围内的销售额、成本必须全部填报且成本大于0，才进入投产比排名。成本0显示“无投放”；有成本但销量0的SKU以ROAS 0参与排名。
- 缺失金额按“未填报”显示；汇总金额只含已填报部分，缺少资料时整体ROAS不计算。文件内同SKU会按币种及资料完整性分别合并，已填报金额不会因另一行缺失而丢失。
- 历史系统的amount由主数据单价估算，不能当作真实收入。迁移保留原字段及销量，新reported_amount、ad_cost、currency均为空，历史记录单独展示“未标币种”。
- 印尼线下销售按实际发货数量/金额减已验收退货汇总，不计未发订单，不重复统计从电商仓分摊扣减的库存。线下未填广告成本时不参加ROAS排名。继续遵循原线下汇总可见权限。
- 无导入日期在趋势中留空，不推断为零销量。管理员冲销导入后，库存恢复且看板同时排除该批销量、销售额及成本。

## 待办提醒

总览所有待办卡片使用红色；高优先级仍有“优先处理”文字。支持展开全部待办，导航展示红色待办数量。待更新销售、待提交月计划、待复核、待审批、待发货等需要行动的状态显示红色，完成业务后自动更新。

## 发布与数据升级

新迁移 `0010_fancy_luminals.sql` 只向sales_records新增三个可空字段；不改写旧迁移，不覆盖历史业务数据。现有独立服务器会在启动时自动执行新增迁移。按仓库原部署流程备份数据后更新代码并重启，保持现有公司登录与存储配置不变。不要只替换前端静态文件：后端与数据库迁移必须一起升级。

## 人民币参考汇总与广告费核对

- 使用 ExchangeRate-API 公开参考汇率（https://www.exchangerate-api.com/docs/free），服务器只请求固定 CNY 基准地址，不发送销售或账户资料。按供应商下一次更新时间自动刷新，使用时抓取并缓存；不是后台主动定时换账。
- 所选历史期间也统一使用最新可用参考汇率，仅供经营比较，不代表交易当日汇率或财务结算值。显示来源、更新时间和异常状态；已标CNY的金额按1折算，其他金额除以该币种每1CNY的单位数。
- 每个站点/渠道/币种先汇总、折算到分，再相加，Excel保留同一快照、换算率、完整性和口径。外币缺汇率时不虚构0；已知金额仍显示，不完整资料不计算整体ROAS。
- 快照超过36小时提示陈旧，超过7天停止外币折算。错误响应、超时及失败请求保留最近可用快照，按一小时退避；备份期间不写缓存。
- 三个以上SKU填写相同正广告费、站点本币不符、有销量零金额均提示人工核对，导入前必须确认。提醒不自动判定重复成本、错误币种或赠品。
- “销售导入管理 → 核对重复广告费”仅处理整批相同正费用：登记人核对当天总费用及依据后，原子清空该批SKU广告费，改记一笔渠道费用；原值写入审计，销量、库存、原批次标识、日报确认均不变。已有有效渠道费用时拒绝覆盖，并发/重复提交不双记。
- 工厂继续只接收销量，看板接口及导出不提供金额、广告费、汇率经营汇总或财务核对提示。
