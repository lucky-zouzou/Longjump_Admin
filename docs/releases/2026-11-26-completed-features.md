# 2026-11-26 完成功能发布范围

本文记录本次发布范围与验收要求。实际发布结果以对应合并记录、部署流水线及正式站运行版本核验为准。

## 本次范围

- **印尼线下销售与分销流程**：新订单按申请、审核、客户确认、放货、派仓、打包、发货及签收推进；履约与回款分别跟进。印尼线下界面支持中文与印尼语切换。
- **国内工厂直发分销**：独立管理客户、报价、合同、放货条件、分批发货与回款，不扣减海外库存。
- **印尼 BD 寄样**：串联合作轮次、寄样申请、审核、仓库执行、签收及成本核对；免费寄样不计销售收入，不产生客户应收。
- **旧海运单作废**：对已通过历史到仓另行登记的旧单，提供有依据的作废操作。需人工确认、关联历史到仓记录并填写原因，保留原单与审计。
- **广告申请与趋势**：增加运营广告预算申请入口、主管审批与独立财务核定；趋势读取实际登记的广告费用，按原币区分，缺报不作零处理。核定预算不等于付款或实际消耗。
- **考勤与飞书同步**：补齐每日打卡、请假及配置入口；增加飞书连接检查、员工精确绑定和只读同步记录。飞书同步默认关闭。
