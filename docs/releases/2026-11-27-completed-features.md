# 2026-11-27 完成功能整合发布

发布范围：BD 寄样申请入口、独立 MCN 寄样、SKU 批量导入、按店铺销售额分摊寄样成本、印尼单店 Agent 试运行、TikTok Shop / 广告连接接口。不包含千问适配。

## 业务入口

- 日常工作 → 印尼 BD 寄样：达人合作申请指引、MCN 机构申请。达人合作清单及 MCN 清单均支持 Excel / CSV 预览导入。
- 人员与财务 → 审批与费用 → 营销投入：样品成本和运费分别核对，按同月印尼 TikTok 各店铺销售额占比归属，保留凭据、版本及关账快照。
- 日常工作 → 单店 Agent 试运行：管理员配置印尼试点店铺、重点 SKU、负责人及数据归属后启用；初始状态关闭。不自动补货、修改广告或发送催拍消息。
- 产品与系统 → 连接与授权：管理员配置并授权 TikTok Shop 和 TikTok 广告后手动读取最近数据。

## 上线后的配置边界

- 现有销售日报未按店铺拆分，财务需要核对各店铺月销售额依据；缺销售额、汇率或成本时显示待核，不自动平均分摊。
- TikTok 接口代码完成不等于已获得官方授权。官方应用凭据、真实店铺及广告账户授权与对账仍待完成；当前不会自动覆盖业务台账或向 Agent 输入新快照。
- 马来西亚店铺不会自动纳入印尼试点。Agent 未确认数据归属时不输出单店经营结论；MCN 内容交付继续由原寄样流程跟进。
- 不随源码发布任何密钥、真实业务数据库或本地预览数据。
