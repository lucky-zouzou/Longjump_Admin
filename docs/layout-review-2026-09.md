# 工作台布局检查与调整（2026-09-27）

## 原则

高频任务先展示，统计与配置按需展开；表格在自己的区域滚动；手机控件保持可读、可点击。此次仅改变前端结构和样式，沿用全部服务端权限、审批、库存及金额口径。

## 调整

| 范围 | 调整 |
| --- | --- |
| 全系统 | 统一标题、说明、表单、卡片和表格字号；手机表单16px、按钮至少44px；修正窄卡片四列表单；长表格独立滚动并固定表头 |
| 每日销售导入 | 运营先看更新状态、批量导入、日报确认、广告费用及批次；经营看板移至末尾按需展开；单条录入折叠；完整日报仍为默认 |
| 补货驾驶舱 | 运营本月需求编辑前置于图表和建议清单；SKU配置、供应参数与复盘按需展开 |
| 新品、海运、库存 | 新品发起、旧版历史海运、批量库存修正收起为明确入口；当前任务与数据仍展开 |
| 主数据 | 合作方与仓库编辑使用两列；打开编辑器时占满一行，避免旁边大片留白 |
| 印尼批发 | 导航放在汇总之前；客户档案、业务检查不重复展示财务指标；统一输入框边界 |
| 外勤 | 移除重复拜访/请假按钮；手机子导航横向滚动；恢复管理员等角色的手机销售人员筛选；保留表单自动定位 |
| 总览、审批、生产、月度、账号、审计 | 应用共享可读字号、表格固定表头和响应式规则，保留业务入口 |

## 验证

- 隔离预览数据库，未修改线上业务数据。
- 1280px桌面、390px手机逐页检查：总览、用户管理、批发、补货、新品、销售、库存、到仓、月度、审批、采购生产、海运、主数据、审计、权限，共15个主模块。
- 手机进一步检查外勤出勤、合同、贡献、库存与新品，及订单、客户、销售看板、财务对账、业务检查；页面无整页横向溢出，宽表格单独滚动。
- 外勤中印尼语检查；登记拜访点击仍定位到表单。
- 运营默认完整日报；需求编辑位于图表之前；折叠单条销售后重新展开仍保留未提交内容。
- 完整测试覆盖业务回归；浏览器检查使用已有测试数据，不能代替所有真实订单、长文本和新品阶段的生产数据验收。
