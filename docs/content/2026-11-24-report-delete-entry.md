# TikTok 数据罗盘：报表删除入口

本次为本地界面调整，未发布、未修改正式数据。底层已有 deletePlatformReport，复用现有权限、版本校验、幂等与追加删除修订机制，不新增另一套删除口径。

## 使用

数据来源选“运营导入报表”时，数据罗盘顶部显示“管理 / 删除报表”。点击后定位至创作者视频明细；操作列在左侧固定显示。每行展示来源文件，点击删除后确认站点、创作者、Video ID、报表期间和版本，填写原因再提交。

运营可删除当前本人提交且仍有站点权限的记录。其他人员显示只读，管理员及运营主管按现有授权管理。删除只作用于选中视频的指定报表期间，保留历史与原因，并重新统计播放量、订单、人民币 GMV。已发布视频观察仍保持独立口径。
