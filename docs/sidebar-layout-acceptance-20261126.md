# 左侧导航布局修复验收 · 2026-11-26

以下为发布前的本地验收记录。验收时尚未推送或部署，未修改真实业务记录；正式发布状态以部署记录和线上版本核验为准。

## 问题与调整

旧导航在固定高度侧栏中，把品牌、搜索、个人工作和账号区置于业务菜单滚动区之外。新增个人工作入口后，业务菜单的剩余高度很小；新主题的较高优先级样式也覆盖了原来的矮屏紧凑样式。手机“更多工作区”同样存在个人入口挤压业务列表的问题。

现在个人入口与业务分组共用一个滚动区。品牌和搜索保持精简，个人入口按两列排列，账号底部只显示姓名和岗位；点开可看邮箱、所属范围及退出登录。菜单保留四组业务分类，默认展开当前业务页面所属分组，个人打卡/请假页保持业务分组收起；支持统一展开、收起和搜索自动展开。发生溢出时显示“下方还有工作区”，可点击继续浏览，到底后可返回顶部。

菜单滚动、账号浮层、快捷入口与手机“更多”沿用实际岗位权限，不扩大接口授权，不改变审批与数据计算。
