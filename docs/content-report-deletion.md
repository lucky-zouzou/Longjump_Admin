# TikTok 运营报表删除

入口：TikTok 内容中心 → 数据罗盘 → 数据来源「运营导入报表」→ 创作者视频明细 → 删除。

- 删除前核对站点、Video ID、报表起止日期和版本，填写删除原因后确认。「先保留」不改变任何数据。
- 运营可删除本人当前提交且仍有维护权限的站点记录；管理员和运营主管可协助删除。拍摄剪辑及其他只读岗位不能删除。
- 删除针对所选视频在所选报表期间的一条记录。不会删除 TikTok 视频、系统发布记录或独立填写的累计观察数据。
- 删除后明细、播放量、归属订单、人民币 GMV、关联覆盖和可选期间均按有效记录更新。日期覆盖或交叉的报表仍沿用原去重规则，汇总不保证只是直接减去该行。
- 删除会新增带删除人、时间、原因的历史修订，并写入审计日志。之前的修订保留，但不会回退为有效数据。重复提交不重复删除；他人已修订的旧版本必须刷新核对。
- 如需重新统计，重新导入核对正确的报表。系统生成新修订；空白指标不会继承删除前的数据。

数据库升级：新增迁移 `0067_content_report_deletion.sql`，不改写现有数据。备份迁移清单已同步。

本次使用独立本地合成数据核验，未删除正式业务记录。权限、统计、并发冲突、重新导入及审计回滚见 `tests/content-platform-report-delete.test.mjs`。

验证（2026-11-23）：类型检查、服务端和 Worker 构建通过，完整回归 939 项全部通过。浏览器实测运营取消/确认删除、他人记录只读、筛选保留和桌面/窄屏布局；测试汇总由 350 次播放 / 6 单 / ¥56.25 更新为 300 次播放 / 5 单 / ¥48.75。确认框居中修正后已重新构建并核对页面。当前仅本地完成，未发布。
