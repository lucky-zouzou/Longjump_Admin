# 达人移交流程本地验收

日期：2026-11-04。依据《达人管理修改意见》，在既有达人协作模块内调整；不发布。

## 对照结果

| 要求 | 本次实现及核验 |
| --- | --- |
| 五个工作区 | 协作总览、达人档案、运营提交、合作与履约、经验复用。分工与组长配置折叠在页头设置。 |
| 运营移交已有出单达人 | 12 列主模板加说明页；单条及批量预览、整批校验、重复跳过；提交即建档。 |
| 一位达人一个档案 | 平台＋账号形成跨国主档案，保留国家/店铺关系，多轮合作独立关联。 |
| BD 接收后直接深度合作 | 接收后为待深度合作，保存责任人与下一步；无需伪造首次触达或回复记录。 |
| 原始评估与 BD 维护分离 | 原始运营版本不可变；后续修订留历史，BD 等级/意向/备注/分配独立。 |
| 权限与待办一致 | 管理员显式指定 BD 组长；普通 BD 只见负责达人。暂不接收及转派后的待办随有效负责人移动，同一提交不重复产生任务。 |
| 暂停与恢复 | 待接收阶段也能暂停，恢复前不能接收；不伪造接收时间或抹去源资料。 |
| 履约与复合作 | 自动带入已有达人，视频/直播按形式显示，已移交达人进入新轮次计入复合作；保留原商业审批与仓库凭据约束。 |
| 合作效果 | 完成后逐轮登记原币 GMV/订单/成本/评价/计划，修订不累加，未知成本保持空值；不自动当财务核验贡献。 |
| 经验沉淀 | 五类可复制方法，记录国家及作者；无需强制绑定已完成轮次。审核后共享，作者不能自审。 |
| 旧记录与备份 | 新增 0039 迁移补建主档案/关联，不修改历史销量、库存或资金；新增表纳入完整备份恢复。 |
