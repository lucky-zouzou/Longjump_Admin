## 修改范围

- 下载直接使用公司提供的《运营移交模板.xlsx》，不重新生成另一套表头。原文件为一个工作表、16列和一行占位示例，未包含真实达人联系方式或业务台账。
- 下载路径：`/templates/creator-operations-handover.xlsx`。2026-11-05 原件 SHA256：`485a646db90fe25869f452d48a2abd412b9cd1cd13146c4bd7065c09286f6fff`。
- 增加“一键导入”：选择文件、所属店铺、实际GMV币种并确认合作依据后，一次点击完成批量校验与提交。可选“仅检查数据”不会写入。
- Excel按单元格实际值读取，日期不再因显示格式变成`11/4/26`而被拒绝；同时支持1904日期系统和UTF-8 CSV。模糊文本日期仍要求修正。
- “已寄样产品”保存在移交及不可改写的历史记录中，并在预览、提交详情、达人档案和协作台账导出中显示；不生成新的样品出库。
- 模板占位示例不可提交。错误显示具体行号和原因，有错误时整批不写入；重复资料跳过，同一达人仍关联原档案。
- 未选店铺或未分配分工时显示原因。配置更新后可刷新继续，不扩大运营跨店权限，不自动指定负责人。
- 选择新文件会清除上一文件预览和确认状态，防止失败后误提交旧文件。旧12列资料格式继续兼容；空白寄样产品不改变既有去重输入。

## 使用

1. 达人与直播BD → 运营提交 → 下载运营移交模板。
2. 替换示例行为真实记录，每批同一店铺，最多50行。
3. 选择店铺、GMV实际币种及填写好的文件，确认合作依据，点击“一键导入”。
4. 有错误按行号修改后重新选文件；成功后交对应BD接收。运营提供的数据不自动计入已核验财务贡献。

正式账号仍须具有管理员或BD组长配置的店铺分工。本次未修改生产分工、未将示例或测试达人写入正式后台。
