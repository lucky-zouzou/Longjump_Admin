# 小品同学

在员工后台顶栏点击「小品同学」，或在「搜索工作区」输入「小品同学，怎么导入销售日报？」并按回车。只输入名字会打开助手。对话内可直接追问「下一步交给谁？」。这是文字口令。

新员工先选「我刚入职，从哪里开始？」。助手按本人岗位列出第一项任务、具体步骤与下一岗位；「打开对应工作区」跳转到实际办理页面。后台菜单和业务表单沿用原权限。公开的分销商家入口不提供这个助手。

- 运营可以问「销售日报只有半天，怎么填？」或「怎么把已合作达人移交给 BD？」。
- 供应链可以问「怎样汇总各站点备货计划？」。管理员可以问「备货计划由谁批准？」。
- 财务可以问「退款后怎么修订每日成本？」。在经营行动指引中点「查看当前经营行动数量」会从本机业务库读取已触发、待核实、待复查的记录数，并显示范围和最近更新时间。运营看到本站渠道，其他有权岗位默认看印尼全部平台。
- 拍摄剪辑可以问「成片怎样交付新版本？」。工厂可以问「接单后在哪里回复交期？」。

## 内部操作与公开资料

保持「自动判断」即可。员工问“运营移交达人怎么提交”“视频效果表怎么导入”等操作时，助手优先读本岗位的手册，给出步骤、工作区入口和交接岗位。遇到表达不清的操作问题，启用的模型可在该岗位有权查看的手册中匹配。请只描述操作，省略客户资料和单号。

问公开知识可选「外部公开资料」。例如“什么是点击率”读取 Google Ads 官方说明，“印尼 2024 年总人口”查世界银行。其他公开主题可用 GPT-5.4 mini 检索网页，答案附来源链接。遇到无法取得来源的问题会提示重新查询。

得到有依据的答案后，系统将操作指引或带来源的公开解答保存到岗位知识库。同岗位同事可从「岗位知识库 · 最近解答」打开。手册变化后按新版本重新匹配。公开答案显示核对日期，常规公开解答在 24 小时内可以复用，含“最新”、政策或费率等时效问题重新查询。无法作答、缺少出处或实时经营数字不会成为可复用知识。

## 部署与维护

正式服务从只读文件读取专用密钥，部署使用 GitHub Actions 加密 Secret `EMPLOYEE_OPENAI_API_KEY`。本地可使用 `LOONGJUMP_OPENAI_KEY_FILE` 指定文件。手册和内置公开数据源可独立使用。核验真实网页检索时选一个公开问题，例如“公开查询：TikTok Shop 印尼站官方卖家学习中心有哪些商品上架指引？”，检查答案标记「公开网页检索」并打开来源。

业务按钮、岗位权限或审批流程变化时，同步更新 `lib/employee-guides.mjs` 和对应的岗位回归测试。
