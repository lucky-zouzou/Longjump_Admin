# MCN 机构独立寄样申请验收

日期：2026-11-27。分支：`codex/bd-sample-entry-20261127`。开发基线：`0eee730`（BD 寄样入口修复）。本次仅本地开发，未推送或部署。

## 使用流程

BD 打开「印尼 BD 寄样」→「MCN 机构申请」，无需选择达人或创建虚拟达人。

1. 选择本人负责的印尼 TikTok 店铺，填写机构名称、联系人、联系方式、合作/项目编号和寄样用途。
2. 填写已签署协议凭据及日期，明确选择「约定内容/推广交付」或「协议明确仅寄样」。前者必须填写交付日期；两者都必须填写约定说明。
3. 填写实际 SKU、数量和收件信息，明确勾选已核对协议及寄样条件，提交申请。
4. 供应链独立审核并锁库，物流派仓，指定仓库凭照片和运单登记实际发货，负责 BD 确认签收。
5. 约定了内容/推广的机构单由负责 BD 单独登记履约时间、凭据与核对说明；签收不会自动完成履约。财务分别核对实际样品成本和运费，不生成销售收入或客户应收。

支持中文与印尼语。列表可筛选「达人合作」「MCN 机构」，机构订单详情显示项目、负责 BD、协议和履约信息；财务导出新增合作方类型与名称。

## 权限与数据约束

- MCN 为独立合作方类型，`creator_id`、`round_id` 均为空，不虚增达人档案、合作轮次或达人交付率。
- BD 只能在其印尼 TikTok 店铺范围申请；其他 BD 不可读取或处理不属于自己的机构单，BD 组长沿用店铺授权范围。
- 申请不扣库存；独立审核才锁库，实际出库才扣减。申请人不能审核本人申请，发货和成本核实沿用现有岗位边界。
- 同店铺、机构、项目编号不可重复生成有效单；重复请求幂等。拒绝或整单取消后可以重新申请，部分已发货的原单保留追溯。
- 机构履约有独立待办及证据，必须已有实际发货才能登记完成。仅寄样订单没有内容待办。
- 维护锁、版本并发检查、财务关账限制、照片权限及不可变审计历史保持生效。
