# 寄样批量导入与店铺销售额分摊验收

日期：2026-11-27。基于本分支既有 BD 申请入口修复与独立 MCN 流程，新增功能仅在本地完成，未推送、未部署、未修改正式数据。

## 使用流程

1. 达人合作需求的「合作 SKU 与样品数量」以及 MCN 机构申请的「样品清单」均提供 Excel / CSV 导入。下载模板，填写 SKU、寄样数量，可附商品名称。每份文件对应一份申请，最多 100 个 SKU，每个 SKU 为 1–10,000 件；相同 SKU 须合并。
2. 选择文件后先预览，存在错误行则整份不能应用。确认导入仅替换草稿明细；提交合作/寄样申请仍沿现有流程，已确认达人合作的数量不能通过导入绕过审批。供应链审核后才锁库，仓库实际发货后才扣库。
3. 财务按实际出库数量核对样品成本，寄样运费独立核对，继续保留唯一凭据和费用修订。
4. 总部财务进入「审批与费用 → 营销投入 → 寄样成本 · 按店铺销售额分摊」，核对全部印尼 TikTok 店铺同月、同一截止日的销售额、币种、来源报表及核对说明。管理员只读；范围财务和其他岗位不能提交该依据。
5. 系统按同月财务汇率换算为人民币销售额，计算店铺占比，再分别分配样品成本和运费。原币及人民币采用整数分、最大余数分摊，合计始终与费用来源一致。可以查看原寄样/出库单、销售额凭据和版本，并导出 CSV。

## 业务口径与边界

- 范围为印尼 TikTok 各店铺；包括达人及独立 MCN 寄样，不跨站点或跨平台分摊。
- 现有 `sales_records` 和 `sales_imports` 只有站点、平台字段，没有店铺字段。因此新增财务核对的店铺月销售额依据，不把站点总额或填报人误认为店铺销售额，也没有宣称已接通店铺 API 自动取数。
- 以费用业务月份匹配同月销售额。当前月按截至日暂算；截止日不足、店铺范围改变、缺汇率、缺销售额或合计为零时待核，不自动平均分摊。
- 未填写不等于零。已发生但未核成本的对应合计保持待核；费用缺汇率不假装为零。
- 分摊是原寄样费用的管理归属，不产生第二笔应付、支付或现金流，不重复扣减逐日利润。免费样品不形成销售收入或客户应收。
- 销售额依据只新增版本，不能覆盖/删除。费用修订采用最新版本，不重复计费；关账快照保留当时依据、金额、店铺与负责人，后续变更不回填历史。
- 月结新增「寄样销售额分摊待核」检查。沿现有月结流程处理例外，未另设自动豁免。
- 新增迁移 `0080_sample_cost_allocation.sql` 及备份清单；维护锁、财务时钟、原子版本校验、备份恢复均覆盖新表。
