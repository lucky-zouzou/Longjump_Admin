# 分销三流程 · 岗位验收与体验优化

日期：2026-11-26。依据：用户本次提供的国内分销、印尼销售、印尼 TikTok BD 寄样业务流程。

## 结论与范围

三条业务分开处理是合理的。现金、赊销、寄卖可以共用实物履约流程，但放货条件、应收形成和结算关闭必须按合同分别判断。样品物流、合作内容、成本核实各自完成，不能用一个“已完成”状态代替全部事实。

本轮在 `codex/distribution-role-audit-20261126` 隔离分支完成；保留此前岗位工作区改动。未推送、未部署、未修改生产业务数据。浏览器使用七个 TEST ONLY 合成岗位账号和隔离 SQLite，并非正式员工账号。预览禁止外部请求及密钥读取。

## 规则与数据验证

- 国内预付、定金、账期及寄卖：合同版本、实际来源和打包、财务实际到账、分批发货签收、实际售出、冲正退款分别追溯。
- 印尼预付：付款截图不能放货；正式指令按当前财务净到账校验；冲正后不能使用旧指令继续发货。
- 印尼账期/寄卖：明确批准条款和到期日；不伪造收款，寄卖余货仍待对账。
- 客户加单：新建订单或退回后关联重提；原发货数量和价格不能直接改写。
- 未付款超时：无资金、无待核凭证且未发货的预留可安全释放；已收款/待核凭证或有效信用条款保留人工核对。
- 分批发货：每批独立照片和物流编号；只按实际数量扣库存。国内直发不扣海外库存，样品只用印尼 TikTok 已建份额。
- 免费样品：不生成销售/应收；样品实际成本与运费分列；签收不完成视频/直播承诺。
- 权限、重复提交、并发、关账及备份恢复有回归覆盖；新增进度提示不替代服务端校验。

## 仍需明确的岗位边界

目前物流与仓库执行账号共用“供应链”系统角色，实际发货、样品执行按指定账号限制；供应链审核入口仍是角色级。若仓库人员不应兼任库存/价格审核，下一步应拆分独立仓库授权，不能只隐藏按钮。此次未擅自调整正式员工权限。

国内模块仍是工厂直发履约子账，不是完整的国内制造成本/仓库系统。飞书真实同步、正式账号配置与生产发布不属于本轮合成分销验收的证明范围。
