# 印尼分销产品素材：本地测试版

2026-11-20。独立分支 `codex/distributor-product-materials`，基于 `5647c05`。上一轮 `codex/scientific-business-upgrade` 的未提交工作保持原样；本分支没有合入、部署、配置生产凭据或邀请真实商家。

## 使用

- 管理员：分销管理 → 产品素材。选择原商品色款 SKU，填写印尼语标题，直传成品文件和封面。图片 JPEG/PNG/WebP ≤20MB；视频 MP4/WebM ≤200MB；封面 ≤512KB。主站仅接收12KB以内元数据。
- 文件直传暂存区，服务端 HEAD 核对类型、大小，再通过存储内条件复制封存到新对象路径。保存为草稿，管理员预览后填写再发布权依据、允许渠道（印尼语）及授权截止日期，再勾选确认发布。
- 管理员按“店铺＋SKU”逐个授权；同款不同颜色使用既有不同 SKU，不依靠标题猜色。没有 SKU 授权，即使原业务账号有商品购买权限，也不能访问产品素材库。
- 新门店仍由原分销建店、审核、邀请激活；在素材页把账号设为“仅素材”。切换权限撤销既有登录会话，商家重新登录，密码不变。待审核或停用账户不能访问。恢复完整业务权限需要管理员明确切换。
- 商家使用原 `/distributor` 登录，印尼语“Materi produk”查看授权文件。列表只加载封面，视频点击后才加载播放器；点“Siapkan tautan unduh”后点击“Unduh berkas”在新标签下载，不拉大文件到前端内存，不在线压缩、转码或打包。
- 原分销账号继续使用原库存、报价、下单、售后和结算流程。仅素材账号在服务器端拒绝这些业务接口，也不能使用旧私密链接绕过限制。
- 售后照片、出库凭证、内部拍摄原片不会自动加入本库。本模块不接受已有内部附件 key，必须单独直传已审核的成品。

## 私有对象存储配置（尚未启用）

Node 服务读取以下环境变量；Worker 使用同名绑定/Secret。必须全部正确配置并显式启用，否则上传、读取列表与链接签发默认关闭。

```text
MATERIALS_ENABLED=0
MATERIALS_S3_ENDPOINT=https://<account-id>.r2.cloudflarestorage.com
MATERIALS_S3_BUCKET=<private-bucket>
MATERIALS_S3_REGION=auto
MATERIALS_S3_ACCESS_KEY=<server-secret>
MATERIALS_S3_SECRET_KEY=<server-secret>
```

使用私有桶，不开启 r2.dev、公用域名或匿名读取。优先独立桶隔离素材权限，沿用现有数据库与主站，无新门户、子域名、素材服务器。S3兼容平台须支持 SigV4、HEAD、CopyObject、条件复制、响应 Content-Disposition；仅构建通过不等于所有兼容厂商已实测。

管理员直传所需 CORS 示例（上线前替换为实际源，测试域名单独配置）：

```json
[{"AllowedOrigins":["https://admin.loongjump.com"],"AllowedMethods":["PUT","GET","HEAD"],"AllowedHeaders":["Content-Type","Range"],"ExposeHeaders":["ETag","Content-Length","Content-Range"],"MaxAgeSeconds":3600}]
```

账号权限仅授予这个桶的对象读写及条件复制所需操作，不给管理全部账户权限。上传文件暂存前缀 `distributor-materials/staging/` 配置至少24小时后删除的生命周期；`objects/` 是发布版本，不能套用同一短期生命周期。异常重试可能留下未引用封存对象，清理前必须按数据库引用核对。数据库备份保存素材元数据、授权与签发记录；远程对象不在原本地附件备份中，桶需配置自己的恢复/备份策略。恢复后同时核验对象存在，再恢复发布。

签名参考 [Cloudflare R2 Presigned URLs](https://developers.cloudflare.com/r2/api/s3/presigned-urls/) 与 [CORS](https://developers.cloudflare.com/r2/buckets/cors/)：文件从 S3 API 域名直传/下载，不通过主站转发。

## 权限与日志口径

- 每次请求验证商家 cookie、会话有效期、店铺版本、启用状态、客户状态、负责销售状态以及 SKU 授权。每次签发在事务里再次验证授权、发布版本和有效期，避免签发期间撤权。
- 所有管理操作保留审计记录，受维护锁约束。财务/运营不能直接发布、授权或扩大外部账号权限。
- 下载链接最长120秒，且不超过内容授权有效期；上传链接300秒。签名绑定对象、方法、时间及上传 MIME。封存使用新对象 key，重放上传链接只能改暂存对象。
- 每店5分钟最多签发240条（含封面和播放），避免重复刷新造成过量请求。页面每页24条，原文件不自动预取。
- **链接是短时持有者凭据**：停用、撤权或下架会阻止后续签发，但此前链接在其剩余有效期内仍可能可用；已经开始的下载或已保存的副本无法靠撤权回收。要立即阻断，须在对象存储禁用该对象/凭据，并评估影响。不能声称“停用后所有旧下载立即断开”。
- `distributor_material_issues.outcome=link_issued` 仅证明主站已签发，purpose 区分封面、播放、下载；不记录签名 URL 或密钥。没有虚构 download_completed 字段。实际完成需要客户端文件完整性验收，存储日志也须区分 Range/中断和完整传输。
- 发布前人工核对原创/采购/授权文件及渠道、地域、期限、肖像和音乐权利。平台音乐或未获再发布授权的达人视频不用于试点。系统的确认勾选是审计证据，不替代权利证明。
