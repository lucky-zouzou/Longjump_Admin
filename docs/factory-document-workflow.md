# 采购、发货通知与装箱清单

## 采购准备与审批

1. 运营在月度计划提交本站点和渠道的 SKU 需求。系统按站点、SKU和生效日期匹配人民币商品成本，显示单位到仓成本、需求金额及成本版本，提交时由服务端保存快照；未匹配与范围未核实分别提示，不按零元计算。
2. 五站双渠道齐套后，供应链在「月度计划 → 采购单准备」按供应商、工厂、产品系列核对汇总结果。数量与目的地来自运营需求，不在采购单中另行改写。
3. 有采购成本明细且各目的站参考值一致时，人民币采购单自动带入采购参考价；只有到仓总成本时不拿总成本充当采购价。供应链逐单核定采购价、币种、交期、联系信息、税率、付款条件及条款；保存草稿，再送管理员审批。成本版本变化后，旧草稿需重新核对。模板中的税率、付款方式和赔偿条款必须逐单确认。
4. 管理员在审批中心核对采购模板单并批准。系统冻结该版本并分配给对应工厂；工厂导出订单、核对并确认接单后开始生产。系统分配不代表已通过邮件或其他外部渠道发送。

已批准采购价、条款和数量不可覆盖。追加需求使用计划变更：供应链为增量准备新采购单，管理员重新审批。已下发的数量不可通过追加变更减少。

## 质检与发货通知

工厂接单时回复承诺完工日。交期临近会提醒供应链；生产完工并经供应链确认质检通过后，供应链在「系列采购生产 → 采购、发货通知与装箱清单」提交通知，由管理员审核后下发工厂。

每张通知对应一张生产单、一个站点渠道和一个目的仓，填写通知编号、计划发货日、收件信息、SKU 数量、包装要求和实际需求依据。页面显示当前可售、在途和与补货驾驶舱一致的预测；缺报或部分日报明确标为待核实。提交时保存参考快照，管理员审核时另看最新参考。多个目的地分别下发；同一生产单可分批发货。

如实际需求变化，供应链可选择新的目的仓，并逐项填写数量从哪个站点、渠道调出。调出量不得占用已发货或其他通知预占的数量，采购总量保持不变。待审时预占调出份额；管理员明确确认调整后，才更新该生产单的发货分配，原已批准采购单及原需求保持不变。后续预测按批准分配减去各站实际已发量计算剩余生产，不按原比例重新摊分。

待审通知不会向工厂开放，也不能上传装箱、登记发货或创建海运。管理员不得审批自己提交的通知。驳回、待发取消释放预占；重复点击和并发操作不会重复下发。已批准通知取消不会自动反向改写已批准站点分配，后续调整仍需另行提交、审核。

尚未发货的通知可填写原因取消并释放数量。工厂已提交发货后只能退回补正，不能直接取消或删除发货事实。

## 工厂装箱与复核

工厂在收到的通知下点击「登记发货并提交装箱清单」：

- 填写实际发货日、装箱单号、物流凭证、发货及检验责任人。
- 每行填写一个 SKU 的单箱件数、箱数、起始箱号和长宽高；尾箱另起一行。数量与体积自动计算，箱号不得重复。
- 上传签字扫描件（图片或 PDF），可补充 Excel 原件；关联凭证后确认货物已实际发出并提交。
- 短发必须说明原因；累计实发不得超过通知数量。

供应链和管理员同步查看明细、附件与记录。供应链复核通过后，从该通知建立海运批次，SKU、数量、目的地由已复核装箱单带入；同一通知不能重复转海运。转单后短发余量恢复为可通知数量。

## 权限、库存与兼容

工厂只能查看分配给自己的已批准采购单、采购价和已批准通知附件。内部到仓成本及成本匹配参考不向工厂开放。销售价、广告成本仍不向工厂开放。其他岗位可通过既有「生产动态」查看节点进度，不获得采购价或装箱附件。

装箱提交、复核及创建运输批次都不增加海外可售库存。后续继续沿用开船交接、海运跟踪、到仓验收与上架流程。

历史通知保留原已下发状态；新通知必须经过管理员审核。旧采购单继续可按原运输流程执行，也可使用新通知流程；新采购单必须完成通知、装箱与复核后才能转海运。所有变更保留人员、时间和处理意见。数据库备份包含采购草稿、通知、装箱数据和私有附件。

导出使用提供模板的字段结构生成三种 Excel：采购订单（附站点需求分配）、发货通知单、商品装箱清单。已填充的历史模板数据不会导入业务系统。
