# 管理后台视觉优化验收 · 2026-11-26

## 本次范围

统一管理后台的视觉基础：深墨绿色导航、柔和灰白底色、绿色主操作、较轻的卡片边框与细线页签。覆盖管理、运营、财务、供应链、工厂、仓库、销售与拍摄剪辑等工作区。

- 统一页面标题、表单标签、按钮尺寸、表格行距及数字对齐。
- 页签采用细下划线，语言切换沿用相同配色，长菜单允许换行或在手机端横向滑动。
- 总览卡片保持独立间距，小品提醒内的任务更紧凑。
- 表头、说明与输入提示提高对比度；红、黄、绿业务状态保持可辨认。
- 小品弹窗保留单一输入焦点反馈、关闭入口与可见的底部提问区。
- 工作区异步加载时显示轻量占位；系统设置为减少动态效果时不播放占位动画。
- 新增键盘「跳到工作内容」入口，含印尼语文案。
- 切换到另一主模块时回到页首；同模块的明细定位保持原逻辑。

此次为界面与导航体验改动，没有调整数量、金额、审批权限、库存或收款规则。独立商家门户及服务端登录页沿用已有样式，不在这份内部工作区主题中强制覆盖。
