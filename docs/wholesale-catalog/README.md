# 印尼库存与批发报价

入口：印尼线下批发 → 库存与批发报价。销售账号默认进入该视图；支持中文及印尼语，手机端商品以卡片展示。

## 业务规则

- 库存：合并印尼 TikTok / Shopee 两个独立份额。可接单量 = 两平台账面可售量 − 两平台预留量。不计待上架、隔离及在途；缺少任一份额或存在负数/预留异常时标为待核实。申请前显示为参考快照，最终库存由订单审批原子校验。
- 只有管理员和财务可以维护成本和报价。按 SKU 填采购、海运、税费、入仓四项单位成本（IDR），真实没有发生的费用填 0；凭据编号、核价理由和有效期必须填写。原币费用由管理端核实换算后录入 IDR，系统不猜汇率。
- 默认成本加成：标准 25%、最低 20%，可逐 SKU 修改加成和最终报价。建议价按所选 IDR 单位向上取整；例如成本 IDR 80,000，对应标准 100,000、最低 96,000。此百分比是成本加成率，不是销售毛利率。
- 发布与停用均新增历史版本，不改写旧报价。销售和供应链响应仅包含公开批发报价，不发送采购成本、费用分项、加成率、成本凭据或核价历史。
- 首次上线不生成正式报价；管理端先核实各 SKU 的真实到仓成本再发布。历史订单保持原来的价格和审核规则。

## 销售申请特价

1. 在商品卡片/列表点击“申请特批价格”，选本人客户，填写 SKU、件数、期望单价和申请依据。
2. 管理员审批，可调整批准单价并设置有效期。低于当前最低价、未核价、过期或停用报价时，必须明确确认价格例外并说明依据。申请人不能自行审批。
3. 销售（或管理员代提交）点击“按特批价申请出库”，核对客户后点击“带入选定报价”。此操作明确替换当前出库草稿商品，避免静默覆盖已有草稿。
4. 特批仅绑定该客户、SKU、批准数量上限、单价及有效期；一次授权对应一张订单。取消或驳回订单后，如需重新使用价格，应重新申请。
5. 出库申请依然需要财务/管理员审批及库存锁定；现金类实际发货仍需确认到账。报价批准、订单申请均不扣库存或预留，只有订单审批预留、实际出库扣减。

## 审核与追溯

- 新订单保存申请时和审批时的报价版本快照。报价更新后，审核人必须刷新并核对最新版本；已批准订单不受新报价影响。
- 普通订单未报价、报价过期或单价低于最低价，需财务/管理员明确勾选价格例外并填写依据。
- 特批、报价发布、出库均沿用操作编号幂等及事务校验。重复提交、价格更新冲突、并发占用同一特批授权不会产生部分订单或重复预留。
- 全量备份包含报价、申请、锁价记录及关联订单；新增表受维护锁保护。
- 批次成本利润透明工作区与此功能一同发布；其独立授权仍不自动授予任何员工。批发核价权限并不等于成本利润工作区权限。
