## 分类工作台及配套增强

财务新增六个分类入口：今日待办、应收与回款、应付与付款、营销投入、资金与对账、月结与分析。原业务岗位入口和原资金账继续保留；范围财务不展示不能打开的中央账册链接。

- 广告预算、充值、消耗、退款、账户余额分列；同账户同币种期间不重叠，来源分配合计不能超过运营原记录。另一财务独立核对后才扣减预算；来源修订后标记待重核，支持保留旧单后重建。本表不再次生成现金支出或广告费用。
- 渠道原始广告费用尚未按组织拆分时，由总部财务分配到账户及组织。范围财务只复核已归属本组织的对账单，不读取渠道原始总额。
- 共用服务费用可按同法人、授权成本中心分摊，要求依据和金额守恒。不凭空补齐历史法人或科目，不自动认定当期净利润。
- 人事可签发已结束月份的摘要，由另一位授权财务签收；来源变化须重新签发。摘要保留本地/飞书来源、最后同步情况及缺口，不包含病情，不自动扣薪或生成工资。
- 运营视频导入显示写入、未变化、匹配/未匹配发布的数量及原因，并跳到数据罗盘。未关联内部发布仍可按运营报表口径统计，不提示成“没有数据”。
- 生产承诺日期与估算日期分列，只按工厂承诺计算逾期；已有活动情景和置信度机制保留，不把预测直接变成生产订单。
- 海运页增加运营参考、工厂下单、装箱系数、本票发运、实收到仓、上架、隔离及剩余数量对照。整张订单与当前分批分开，不把多批重复累计或泄露其他站点分配。
- 费用复核与广告审批待办分开跳转；付款经办人不会收到自己的更正复核任务。

## 金额和历史口径

1. 银行到账不同于订单核销；同一笔银行收款分配多单不新增现金。
2. 应付未核销不同于未付款；尚待银行核对的付款必须先核对，不能重复付款。
3. 付款冲正和重录属于记账更正，在当前记账期单列，不描述为又发生一笔转账。
4. 采购应付、期间服务账单、广告消耗和样品实物成本分别保留，不能都直接当现金或公司净利润。
5. 缺汇率不输出完整人民币合计。旧关账快照缺少新增字段时明确提示，不能用现在的数补过去的历史。
6. 小品的“下周付款”采用下一个自然周，另列已逾期；缺到期日保持待核，不能据此建议延期。
