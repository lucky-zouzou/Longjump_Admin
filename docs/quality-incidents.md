# 售后及品质交付异常协作

供应链现在可在“售后反馈”登记五站 TikTok / Shopee 售后，明确选择站点与渠道。运营仍仅登记本人范围；任何登记人的草稿及证据仅本人可见。提交后沿用管理员、供应链、工厂共享范围，定责、应赔及赔付登记仍由管理员操作，不新增财务审批权。

供应链“供应与履约 → 品质与交付异常”用于出厂后的包装、标签、标识、产品品质、数量及运输破损问题。管理员和工厂可查看已提交记录、补充意见，供应链负责录入和整改。与买家售后台账分开汇总；同一买家问题已有售后记录时应在原记录跟进，避免重复追偿。

| 发现阶段 | 发现环节 |
| --- | --- |
| 售前 | 入国内集运仓、入海外仓 |
| 售中 | 打包出库时、买家到手前 |
| 售后 | 买家到手后反馈 |

记录包含发现时间及时区、具体地点、异常类型、SKU/商品标识、件数、情况描述、工厂和仓库线索，以及至少一项采购单/运输单/生产入库批次。单号仅为追溯线索，不据此改变关联订单状态。发现时间保存为当地值、时区及UTC，月份按实际发现地日期归集；原发现日期、站点、渠道、单号、SKU锁定，误录可作废并重建。

先保存草稿，再上传照片并提交；仍使用真实文件格式校验、每份10MB、每条最多6张、哈希去重及原记录权限。记录即时处置与整改措施（含跟进人、期限）；管理员核实责任和应赔金额，赔偿结清且整改说明已填写后才能结案。估计损失可留空，不等于应赔，也不把未知损失当成已确认0。不同币种分开统计。

按发现环节、月份、状态、异常现象和关键词筛选，可导出追溯CSV。图表仅统计已提交且未作废记录，待办跨月保留。录入、证据、意见、定责、赔付、结案、作废均留痕，使用版本校验及原子事务。不会自动调整库存、销售、质检状态或发起付款。

财务核销表单的“回款凭证 / 财务附件”改为顶部独立上传区，支持图片/PDF、单份20MB、每条记录10份。待审批订单也可先上传审核附件，历史财务记录可补传；仅管理员与财务可读。上传文件不表示到账或审批通过。该能力沿用既有存储和API。

迁移0025仅新增记录分类和索引，旧数据默认“售后反馈”，不自动改写旧金额或移入异常台账。部署前须按既有流程备份。
